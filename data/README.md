# Данные для воспроизведения статьи

Это **компактная поставка из предоставленного рабочего архива**, без тысяч промежуточных рисунков.

| Файл | Содержание |
|---|---|
| `isc_mw_1960_2021.csv.gz` | Гомогенизированные величины Mw и регионы (таблица, выгруженная исходным `experiment_28/fe.py` из `master_mw_catalog`). Основной анализ берёт только 1965–2021 годы |
| `neic_mb_1973_2021.csv.gz` | Исходные магнитуды mb и регионы NEIC; записи начинаются в 1973 году |
| `rfm_доверительные_интервалы.csv` | Годовой ряд b с 95% интервалами из `latex_supf_b_data.txt` |
| `rfm_кривая_F_из_статьи.csv` | Опубликованные точки F-кривой из `latex_supf_f_curve.txt` для сверки |
| `bpositive_neic_итоги.csv` | Агрегированные региональные b-positive для порогов 3,5 / 4,0 / 4,5 |
| `bpositive_isc_итоги.csv` | Агрегированные региональные b-positive (все события / Mw ≥ 4,0) |

**Изменения имён:** архивная таблица `NEIC_Mw_1965_2021_M3.5_with_FE.csv` была получена SQL-запросом из `earthquakes_gr_low.master_mw_catalog`, а не из NEIC. Здесь она названа `isc_mw_1960_2021.csv.gz` по фактическому происхождению и диапазону годов.

`run.py` пересчитывает из ISC-каталога RFM и MLE; таблицы b-positive из оригинальной архивной обработки уже подготовлены для иллюстраций 6–8. Для полной независимой проверки первоначальной GOR-гомогенизации не хватает набора исходных пар магнитуд и её коэффициентов.
